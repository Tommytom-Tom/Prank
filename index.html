Comment cette animation est-elle créée ?

Le script Python dessine les images avec Pillow, puis les assemble en GIF. GitHub Pages affiche le fichier généré : Python ne s’exécute pas dans cette page.

Pour modifier l’animation, régénérez macarena.gif sur votre ordinateur avec python3 animation2.py, puis publiez le fichier mis à jour.
